# Changelog

## 1.3.0

- Persist output state and Comelit parameter memory in `/data/state.json`.
- Add `module-type` and per-module `type` configuration metadata.

## 1.2.0

- Add compact `module-addresses` configuration for multiple virtual I/O modules.
- Keep optional advanced `modules` configuration for custom names and states.

## 1.1.0

- Add Comelit memory read/write command handling for module parametrization.
- Respond to page and non-page parameter commands used by SimpleProg.

## 1.0.0

- Initial add-on release.
- Add Comelit bus responder for virtual 8-output I/O modules.
