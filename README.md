# Comelit Virtual Module Add-ons

Home Assistant add-on repository for virtual Comelit bus modules.

## Add to Home Assistant

Use this repository URL in Home Assistant:

```text
https://github.com/VanHelsing2048/VirtualComelitModule
```

The add-on is available in the `VirtualComelitModule` folder.

## Versioning

The repository keeps the current add-on version in `VERSION`.
The Home Assistant add-on version is declared in `VirtualComelitModule/config.yaml`.
